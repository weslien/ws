WORKSPACE GRAPHS · v0.6.0

Mutable workspaces
from immutable layers

Workspaces form from layers, other workspaces, or a git repo. Branch from another workspace's uncommitted state without Git index races. Keep what you want as a new layer; drop the rest. JSON output for agent coordination. 10 reproducible multi-agent scenarios.

CORE PRIMITIVES

Layers, workspaces,
and the graph between them

Layer

An immutable, content-addressed directory at ~/.ws/layers/<hash>. Can't be modified after creation. The unit of sharing.

Workspace

A mutable working directory created from a layer. keep promotes it to a new layer; drop deletes it.

Graph

The provenance chain: parent → parent → base. ws graph prints this tree so you know where a workspace came from.

HOW IT WORKS

Branch from
uncommitted state

A workspace can branch from another workspace's current state — including uncommitted changes. The base layer is never modified, so branching is safe and instant. No Git index to race against.

Read the worked example
ws — workspace graph
$ ws get base:https://github.com/you/project --name=feature-a --json {"workspace":"feature-a","formed_from":"a3f4d9c2e1b5"} $ ws get ws:feature-a --name=feature-b workspace feature-b formed from 8c2e1... $ ws keep feature-a --message="added lodash" --json {"workspace":"feature-a","layer":"8c2e1ba7d3f4"} $ ws status --json {"workspaces":[{"workspace":"feature-a","layer":"8c2e1ba7d3f4","dirty":"no"}, ...]} $ ws graph feature-b ws:feature-b [active] └─ layer:8c2e1ba7d3f4 [added lodash] └─ layer:a3f4d9c2e1b5 [base:https://github.com/you/project#HEAD]

COMMANDS

The command set

Full reference
ws get

Create a workspace

From a layer, another workspace, or a git repo URL.

CREATE
ws run

Run a command

Execute inside the workspace filesystem. Writes go to the private overlay.

EXEC
ws diff

Show differences

Against the base layer, or against another workspace.

DIFF
ws keep

Save as a layer

Commit workspace changes into an immutable, content-addressed layer.

SAVE
ws drop

Delete a workspace

Removes the workspace and all uncommitted changes. Base layer is untouched.

DELETE
ws graph

Print the graph

Full layer + workspace DAG, or a single workspace's provenance tree.

INSPECT
ws layer ls

List layers

Every layer in the local store with its hash and parent.

LIST
ws layer gc

Collect garbage

Remove layers no longer reachable from a live workspace.

GC
ws status

Show all workspaces

Table with dirty/clean state, layer, message, and created timestamp. --json for agents.

INSPECT
ws path

Print workspace path

Resolve a workspace name to its filesystem path. No hardcoding.

PATH
ws export

Export workspace

Copy workspace contents to an external directory for git commit.

EXPORT
ws layer copy

Copy from a layer

Copy a file from an immutable layer to a destination path.

COPY
--json

MULTI-AGENT

10 scenarios for
parallel agents

Plan-execute-consolidate. Parallel code review. Bug hunts. Iterative refactoring with rollback. The built-in skill teaches agents how to use ws for coordination — with --json output, ws status for cross-agent visibility, and ws layer copy for merging.

ws — plan-execute-consolidate
