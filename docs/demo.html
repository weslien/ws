MULTI-AGENT DEMO · CALCULATOR API

7 agents. 3 waves.
1 merged binary.

Seven AI agents build a Go calculator API in parallel. Four implement independent endpoints; two branch from their parents to add validation and logging; one consolidates everything into a single compilable binary. Battle-tested across 100 scenarios.

HOW IT WORKS

Parallel agents,
shared layers

Wave 0 creates a base layer from a Go skeleton. Six agents each get a workspace branched from that layer. Four work in parallel on independent endpoints. Two branch from wave-1 agents — inheriting their uncommitted state — to add dependent features. The consolidator merges all layers into one binary.

THE WAVES

Three waves of work

Wave 0 — Setup

1 layer · 6 workspaces

A base repo with four stub handlers gets committed. ws keep saves it as a layer. Six workspaces are branched from that layer — one per agent.

ws — setup
$ ws get dir:/tmp/ws-demo-repo --name=base --json {"workspace":"base","formed_from":"5eb8d32459ce"} $ ws keep base --message="base: calculator API skeleton" --json {"workspace":"base","layer":"e3b0c44298fc"} $ ws drop base $ for i in 1 2 3 4 5 6; do > ws get layer:e3b0c44298fc --name=agent-$i --json > done

Wave 1 — Parallel implementation

4 agents · 4 layers

Four agents implement independent features in parallel. Each builds, then ws keep saves the result as a new layer.

agent-1add + subtract handlersfrom base
agent-2multiply + divide handlersfrom base
agent-4/health endpointfrom base
agent-6/metrics endpoint with request countingfrom base
ws — wave 1
$ ws run agent-1 -- go build -o /dev/null main.go $ ws keep agent-1 --message="agent-1: add+subtract" --json {"workspace":"agent-1","layer":"a1b3c2..."} $ ws run agent-2 -- go build -o /dev/null main.go $ ws keep agent-2 --message="agent-2: multiply+divide" --json {"workspace":"agent-2","layer":"d4e5f6..."} $ ws run agent-4 -- go build -o /dev/null main.go $ ws keep agent-4 --message="agent-4: /health endpoint" --json {"workspace":"agent-4","layer":"g7h8i9..."} $ ws run agent-6 -- go build -o /dev/null main.go $ ws keep agent-6 --message="agent-6: /metrics endpoint" --json {"workspace":"agent-6","layer":"j0k1l2..."}

Wave 2 — Dependent branches

2 agents · 2 layers

Two agents branch from wave-1 workspaces — inheriting their uncommitted state. Agent-3 adds validation on top of agent-1's handlers. Agent-5 adds logging on top of agent-2's.

agent-3input validation (missing params, type checks)from ws:agent-1
agent-5structured logging middlewarefrom ws:agent-2
ws — wave 2
$ ws get ws:agent-1 --name=agent-3 --force workspace agent-3 formed from a1b3c2... (uncommitted) $ ws get ws:agent-2 --name=agent-5 --force workspace agent-5 formed from d4e5f6... (uncommitted) $ ws run agent-3 -- go build -o /dev/null main.go $ ws keep agent-3 --message="agent-3: input validation" kept layer m3n4o5... $ ws run agent-5 -- go build -o /dev/null main.go $ ws keep agent-5 --message="agent-5: structured logging" kept layer p6q7r8...

Wave 3 — Consolidation

1 agent · 1 layer

The consolidator branches from agent-3 (which already has validation + add/subtract), then merges all six agents' code into one file. Builds and saves as the final layer.

ws — wave 3
$ ws get layer:$LAYER3 --name=final --force $ # merge using layer copy from each agent $ ws layer copy $LAYER_2 main.go /tmp/agent-2.go $ ws layer copy $LAYER_4 main.go /tmp/agent-4.go $ ws layer copy $LAYER_5 main.go /tmp/agent-5.go $ ws layer copy $LAYER_6 main.go /tmp/agent-6.go $ # manually merge features into final workspace $ ws run final -- go build -o /dev/null main.go $ ws keep final --message="consolidated: all 6 agents merged" --json {"workspace":"final","layer":"787bb50a1ef3"} $ ws export final /project/dist exported workspace final to /project/dist
